title: Recording pill
description: The glass capsule that shows Warble is listening.
---

While you dictate, a small Liquid Glass pill floats above the Dock on the screen your pointer is on. It never takes focus and clicks pass straight through it.

It is one piece of glass that changes shape rather than a set of separate views: a wide capsule while you speak, a small one while Parakeet works, and a circle with a check mark once the text is typed.

<PillStage />

| State | What you see |
| --- | --- |
| Listening | A red dot and bars that follow your voice. |
| Transcribing | Three rippling dots while Parakeet works. |
| Typed | A green check for a moment, then the pill fades. |
| Problem | A red-tinted pill with a short reason, and a low tone if sounds are on. It clears after five seconds. |

### When nothing was typed

A dictation that produces no text says why instead of quietly disappearing:

| Message | Meaning |
| --- | --- |
| No sound from the microphone | The recording was silent. Check the input in **Settings → Audio**. |
| No sound from system audio | **Listen to** is set to system audio and nothing was playing. |
| No sound recorded | Neither the microphone nor system audio had sound. |
| No words recognized | There was sound, but Parakeet heard no words in it. |
| Screen Recording permission needed | System audio capture was refused. See [Troubleshooting](/docs/troubleshooting). |
| Microphone unavailable | macOS would not start the microphone. |

Turn it off in **Settings → Feedback → Show recording pill**. The menu bar icon animates the same states either way.
